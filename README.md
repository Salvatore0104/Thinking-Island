# 4–6岁儿童思维课（平板端）项目

## 项目定位

为一名4岁、认知水平约5–6岁的儿童设计的家庭思维课程。课程不是“提前学小学算术”，而是通过故事、操作、游戏、表达和现实任务，系统发展：

- 执行功能：注意、工作记忆、抑制控制、认知灵活性
- 数学思维：分类、模式、数感、运算、测量、数据、图形与空间
- 逻辑与问题解决：比较、排序、排除、条件推理、策略选择
- 科学与计算思维：观察、预测、验证、分解、顺序、纠错
- 元认知与表达：说出发现、解释理由、复盘方法、迁移应用

## 默认学习节奏

- 每周3节主课，每节15–20分钟
- 每周1个线下家庭任务，5–15分钟
- 每12周为一个阶段，共48周、144节主课
- 平板每次只承载短时、高质量互动；课程必须包含离屏操作和亲子对话

## 最重要的实施原则

1. 以能力定级，不以年龄定级。
2. 内容可以超前，呈现方式不能超龄。
3. 先实物、再图像、后符号；先理解、后熟练。
4. 让孩子解释“为什么”，而不只记录对错。
5. 难度保持在“需要想一想，但多数时候能成功”的区间。
6. 不使用倒计时、排名、连续登录奖励或惩罚性红叉。
7. 若连续两次明显抗拒、疲劳或情绪失控，当天结束，不追加训练。

## 第一阶段落地建议

先不要一次开发144节内容。建议用“首月12节”完成最小可用版本，验证以下四件事：

- 孩子能否独立理解语音指令
- 15–20分钟是否合适
- 哪类交互最能引发主动思考和语言表达
- 自适应升降级是否让孩子既不无聊也不挫败

验证后再批量生产第2–12月内容。
